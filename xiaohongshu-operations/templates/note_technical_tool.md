标题: Mac离线接口调试，换到Bruno清静了

最近做本地开发调试，被商业接口工具强制登录和后台常驻吃掉快1.5G内存搞得有点烦躁。加上很多内网接口涉及敏感鉴权，在线同步总觉得心里不踏实。

顺手把工作流切到了纯离线的Bruno v1.38。安装直接用官方包或者命令行：
brew install bruno

用了两周比较爽的三个地方：
1. 纯本地离线运行，所有的接口收藏夹直接存成当前工程目录下的明文文件，用Git就能做版本管理，完全没有云端泄露风险。
2. 启动飞快，冷启动实测不到1秒，日常内存占用稳定在120MB左右，比以前动辄几百MB的庞然大物清爽太多。
3. 脚本调试直接支持JavaScript语法，环境变量切换不需要联网同步。

如果平时对数据隐私比较敏感，或者只想安安静静调试个本地API，这种不折腾云端同步的离线小工具确实省心不少。大家本地调试接口一般习惯用哪款？
